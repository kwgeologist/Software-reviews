# 10. IHS 298 full-API identity

This is a high-priority audit item.

The full **14-digit API/UWI** is the production well identity.

Examples:

- `42401123450000`
- `42401123450001`
- `42401123450002`

These must remain distinct wells.

Verify:

1. Exact 14-digit match is attempted first.
2. No normalization collapses completion suffixes.
3. Missing full API creates a new well.
4. Lease/operator/field are populated from the 298 where available.
5. Location is only assigned when valid datum handling permits it.
6. Different 14-digit APIs are never combined merely because the first 10 digits match.
7. Duplicate production key is effectively:
   **full API + production month**
8. Same month on different completion APIs is not considered a conflict.
9. Same full API/month identical row is skipped.
10. Same full API/month differing row is handled as an actual conflict.

Search the entire production/import codebase for helper functions that reduce APIs to 10 digits and make sure none are accidentally used in the 298 identity path.
