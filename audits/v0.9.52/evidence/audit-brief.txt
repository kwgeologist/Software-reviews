# 18. Parallel Tk Test Crashes

This needs explicit review.

Recent full-suite runs have shown **segmentation faults in different Tk GUI tests under parallel workers**, while those same test files pass when run alone.

Investigate:

- whether Tk tests are being executed concurrently;
- whether GUI tests share Tcl/Tk state across workers;
- whether test isolation is unsafe;
- whether these are product crashes or test-harness crashes.

Determine whether Tk-dependent GUI tests should:

- run serially;
- be marked to exclude them from parallel workers;
- use a dedicated worker group.

Do not dismiss the crashes merely because individual files pass.

Classify clearly:

- product defect;
- test-harness defect;
- unresolved.
