Geo Workbench and the Well Manager

Add or edit formation tops

Where: Geo Workbench ▸ Well Manager ▸ FM Tops tab

  1. Select the well and open the FM Tops tab. Sources: … above the table opens a checklist (Select All, Clear All, a box per source) that stays open while you tick; the table shows the sources ticked.
  2. Choose the Formation (or type a new name), type one of MD, TVD or TVDSS (the others follow from the survey and KB), and the Source.
  3. Press Add for a new pick, or select a pick and Update. The table also takes typing and pasting from Excel.

Notes

  • A well may hold several sources' picks of the same top; new picks use the project's active source unless another is typed.

Change well symbols and status

Where: Geo Workbench: Wells ▸ Well Symbols…; one well: Well tab ▸ Well Symbol ▸ Choose…

  1. For one well: on the Well tab press Choose… beside Well Symbol, pick the symbol and Save well.
  2. Wells ▸ Well Symbols… shows the symbol catalogue.

Create or open a project

Where: Geo Workbench: File ▸ New Project… / File ▸ Open Project… (File ▸ Recent Projects)

  1. In Geo Workbench choose File ▸ New Project… to make a new project, or File ▸ Open Project… to open one (File ▸ Recent Projects lists those opened lately).
  2. Choose the folder and name. A project is one .ogwdb file that every Workbench program shares.
  3. Set the project's coordinate system with Project ▸ Coordinate System… before importing located data.

If it does not work

  • New and Open are refused after the license expires: save and close still work; install a license or use Recovery Access to look at a project read-only.

Edit a well's header

Where: Geo Workbench ▸ Well Manager ▸ Well tab

  1. Select the well in Geo Workbench's well list.
  2. On the Well tab change the header fields.
  3. Press Save well.

If it does not work

  • Edits are refused after the license expires (the project is then read-only for new work).

Enter or import production

Where: Well Manager ▸ Production tab; many wells: Project ▸ Import Production (many wells)…

  1. Select the well and open the Production tab.
  2. Type a month's volumes in the table (the blank row at the bottom adds a month), or Add month, or paste from Excel. Import… brings in a file for this well.
  3. For many wells use Project ▸ Import Production (many wells)… (matched by API/UWI).

Notes

  • Oil and water in bbl, gas in Mcf, BOE with 6 Mcf = 1 boe.

Import IHS 297 well data or IHS 298 production

Where: Geo Workbench: Project ▸ Import IHS 297… / Project ▸ Import IHS 298 Production…

Before you start

  • A project is open.
  1. Open the project in Geo Workbench.
  2. For well headers, tops and tests choose Project ▸ Import IHS 297… and pick the 297 file (.97f, .297 or .txt).
  3. For monthly production choose Project ▸ Import IHS 298 Production….
  4. Review the preview and import.

Import a Petra project file (PPF)

Where: Geo Workbench: Project ▸ Import Petra Project File (.PPF)…

Before you start

  • A project is open.
  1. Open (or create) the project in Geo Workbench.
  2. Choose Project ▸ Import Petra Project File (.PPF)… and pick the .ppf file. Workbench scans it first.
  3. In the preview, check the record summary and diagnostics; choose the latitude/longitude datum if the file does not state it, and how Existing wells are treated.
  4. Leave "Load digital log curves (written as LAS files)" ticked to bring in the logs, then import. Progress shows well by well; Cancel writes nothing.

If it does not work

  • Nothing can be imported when the file does not state its depth unit (DEFUNITS).
  • A file without a stated datum needs one chosen in the preview, or nothing is imported.
  • Import is refused after the license expires.

Import wells from a CSV or Excel file

Where: Geo Workbench: Project ▸ Import Wells/Data from CSV or Excel…

Before you start

  • A project is open.
  1. Open the project in Geo Workbench.
  2. Choose Project ▸ Import Wells/Data from CSV or Excel… and pick the file.
  3. Tell Workbench what each column is (well name, API/UWI, coordinates, tops and so on); columns left as Ignore are not imported.
  4. Review the preview, choose how existing wells are treated, and import.

If it does not work

  • Wells without coordinates import but do not show on the Map until a location is given.
  • Latitude/longitude need the project's coordinate system (Project ▸ Coordinate System…) to be placed in map X/Y.

Load or edit a directional survey

Where: Well Manager ▸ Location tab ▸ Directional Survey Manager…; many wells: Project ▸ Bulk Load Directionals…

  1. Select the well, open the Location tab and press Directional Survey Manager….
  2. Import file… (CSV, text or Excel with MD, Inc, Azi or TVD, N/S, E/W), Paste…, or type a Manual survey point.
  3. For many wells at once use Project ▸ Bulk Load Directionals….

Record IP and formation tests

Where: Geo Workbench ▸ Well Manager ▸ Tests tab

  1. Select the well and open the Tests tab; choose IP Tests or FM Tests at the top.
  2. Press Add (or Duplicate), fill in the fields, treatments (IP) or recoveries (FM).
  3. Press Save (Cancel puts the saved values back). Mark Preferred marks the well's preferred test.

See a well's treatments (linked to a test or standalone)

Where: Geo Workbench ▸ Well Manager ▸ Treatments tab

  1. Select the well and open the Treatments tab: every treatment of the well, by depth.
  2. Linked test names the IP test a treatment was done for; "standalone" means it belongs to the well alone (for example a Petra TREAT on no IP test's interval).
  3. Treatments of a test are edited with the test on the Tests tab.

Notes

  • A Petra PPF import keeps every treatment: linked to the IP test on its interval, else standalone. Re-importing the file never duplicates them, and nothing is deleted because a file lacks it.

Work in the Well Spreadsheet

Where: Geo Workbench: Wells ▸ Well Spreadsheet… (or Spreadsheet… button)

  1. Choose Wells ▸ Well Spreadsheet….
  2. Pick the well set (the list, the working selection, every well, a saved list...) and the columns: header, tops (MD, TVD, TVDSS), zone values (PhiH...), well values, production totals.
  3. It reads the project when filled: it is a view of the data, not a copy.

The Map

Add a shapefile to the Map

Where: Map ▸ Layers tab ▸ Functions ▾ ▸ Add Shapefile…

Before you start

  • A project is open and the Map is open.
  1. Open the Map (Geo Workbench: Project ▸ Map).
  2. On the Layers tab open Functions ▾ and choose Add Shapefile…, then pick one or more .shp files.
  3. For each file choose Create New Layer (or Append to Existing Layer to add it to a layer of the same geometry), then OK.

If it does not work

  • Only layers of the same geometry (point, line or polygon) are offered for Append.
  • A shapefile in another coordinate system needs its .prj and the project's coordinate system set.

Append another shapefile to an existing layer

Where: Map ▸ Layers tab ▸ Functions ▾ ▸ Add Shapefile… ▸ Append to Existing Layer

Before you start

  • The existing layer is in the project.
  1. Open the Map and go to the Layers tab.
  2. Open Functions ▾ and choose Add Shapefile…, then pick the new file (for example the next county's abstracts).
  3. In the Add Map Layer dialog choose Append to Existing Layer and select the layer (for example Abstracts) in the list.
  4. OK: the features join that layer and take its style; the layer's sources list both files.

Constraints

  • Only layers with the file's geometry are listed: points into a point layer, lines into a line layer, polygons into a polygon layer.

If it does not work

  • The layer you want is not listed: its geometry differs from the file's.

Change a grid's display (Grid Display)

Where: Map ▸ Grid Display… (also Grids tab ▸ Functions ▾ ▸ Display…)

Before you start

  • The project has a grid.
  1. Open the Map. Select the grid on the Grids tab (or make it the Active grid).
  2. Choose Map ▸ Grid Display… on the toolbar (the same dialog as Grids tab ▸ Functions ▾ ▸ Display…).
  3. Set Color fill (Fill with color, Banded, Color bar, Reverse, Show Color Bar, Color range From data or Manual, Opacity), Contour lines and Labels.
  4. Show Color Bar (also Map ▸ Show Color Bar) shows or hides the bar beside the map; a saved color bar is labelled at its stops (0, 0.2 … 6.0).
  5. Apply to see it; OK keeps it with the project; Cancel puts the display back.

If it does not work

  • Map ▸ Grid Display… is greyed out: the project has no grid yet.
  • Several grids are shown and none is selected or Active: Workbench asks which one.

Digitize into the active layer

Where: Map: Layers tab ▸ Functions ▾ ▸ Set Active, then toolbar ▸ Drawing

  1. On the Layers tab select the layer to draw into (a drawing layer, or a map layer), then Functions ▾ ▸ Set Active. Functions ▾ ▸ New Layer… makes a new drawing layer, Active at once.
  2. On the toolbar open Drawing and choose Polygon, Fault Polygon, Line, Contour or Text.
  3. Click to place points (hold and drag to draw freehand); double-click, Enter or Finish ends the shape.
  4. Drawing ▸ Undo / Redo step back and forward.

Constraints

  • A map (shapefile) layer made Active takes drawings of its own geometry only.

If it does not work

  • With no Active layer Workbench asks which layer the drawing goes into.

Edit or save a color bar

Where: Map ▸ Grids tab ▸ Functions ▾ ▸ Color Bars… (or Edit color bars… in Grid Display)

  1. Open Functions ▾ ▸ Color Bars… on the Grids tab (or Edit color bars… in the Grid Display dialog).
  2. Pick a bar on the left (New starts one). Set Min / Max (From data or Manual).
  3. Change stops: select one, Color… to recolour, Add stop…, Delete stop, Reverse, Even spacing; Bands (0 = smooth).
  4. Save (or Save as…) keeps it in the shared library: Map, Geosteer, Petro, Cross Section and Correlation all offer it. Close without saving leaves the saved bar as it was.

Export a grid (ZMAP, XYZ or contour shapefile)

Where: Map ▸ Grids tab ▸ Functions ▾ ▸ Export…

  1. Select the grid on the Grids tab and choose Functions ▾ ▸ Export….
  2. Choose the format: ZMAP+ grid, Grid nodes as XYZ text, Contour lines as a shapefile, or Data points as XYZ text.
  3. Choose map X, Y or latitude/longitude (WGS 84), then Export… and the file name.

Constraints

  • ZMAP+ grids are always in map X, Y.
  • Latitude, longitude needs the project coordinate system set in Geo.

Generate color-bar stops every Step (Min / Max / Step)

Where: Color Bars editor: Min / Max / Step ▸ Generate Stops

  1. Open the Color Bars editor (Grids tab ▸ Functions ▾ ▸ Color Bars…, or Edit color bars… in Grid Display).
  2. Choose Manual and type Min and Max (for example 0 and 6).
  3. Type the Step (for example 0.2) and press Generate Stops (or Enter in Step): 0 to 6 by 0.2 makes 31 stops.
  4. The stops take the bar's own colours along its length. Save to keep it; Close leaves the saved bar unchanged.

Constraints

  • Step must be above zero and Max above Min; at most 1000 stops.
  • When the Step does not reach Max exactly, Max is added as the last stop (0 to 5.1 by 0.2 ends 5.0, 5.1).

Import a grid (Petra, ZMAP or XYZ)

Where: Map ▸ Grids tab ▸ Functions ▾ ▸ Import Petra Grid… / Import ZMAP… / Import XYZ…

  1. Open the Map and go to the Grids tab.
  2. Open Functions ▾ and choose Import Petra Grid…, Import ZMAP… or Import XYZ….
  3. Pick the file; the grid is added to the project and listed on the Grids tab.
  4. Use Map ▸ Grid Display… (or Functions ▾ ▸ Display…) to set its colours and contours.

Notes

  • An imported grid keeps its values as read: Regrid does not apply to it.

Make a grid (gridding project data)

Where: Map ▸ Grids tab ▸ Functions ▾ ▸ New Grid…

  1. Open the Map and go to the Grids tab.
  2. Open Functions ▾ and choose New Grid….
  3. Choose the Data (a formation top, a well value, a zone value, an XYZ file...), the wells and the Grid name.
  4. Set the gridding method, cell size, area, honoring and faults as needed, then Grid. The grid is made in the background (Cancel gridding stops it).

Make an isopach (thickness) map

Where: Map ▸ Grids tab ▸ Functions ▾ ▸ Isopach / Thickness… (also Project ▸ Batch Calculations…, Isopachs tab)

  1. Open the Map and choose Grids tab ▸ Functions ▾ ▸ Isopach / Thickness….
  2. Formation tops tab: choose the upper and lower tops (and Picks from), then Calculate: thickness = lower minus upper in every well with both picks.
  3. Keep the result: Save as well attribute or Save as zone attribute, Grid on the map, or Export XYZ….
  4. For two surfaces use the Seismic horizons / grids tab, then Save grid and show on the map.

Constraints

  • A time surface is never subtracted from a depth surface.

Post bubbles (Bubble Map), for example PhiH

Where: Map toolbar ▸ Bubble Map…

  1. Make sure the value exists: a Petro pay flag on a zone of a project well is saved to Geo as zone values ("<pay name> phi-h", net, N:G...); Project ▸ Batch Calculations… can also make PhiH for many wells.
  2. Open the Map and press Bubble Map… on the toolbar.
  3. Add a bubble set: choose the Value (for example "Zone value: <zone> — <pay> phi-h"), Size (Constant or Scaled to a range), Range and Color.
  4. Tick Show the bubble map and press Apply; it is kept with the project.

Set grid contours (interval, labels, smoothing)

Where: Map ▸ Grid Display… ▸ Contour lines / Labels

  1. Open Map ▸ Grid Display… for the grid (or Grids tab ▸ Functions ▾ ▸ Display…).
  2. Under Contour lines tick Show contours; set Contour from / to, Minor interval and Major interval (blank: automatic), line widths and Color.
  3. Grid smoothing smooths the surface only for contouring (the grid is not changed); Contour line smoothing draws smoother lines.
  4. Under Labels tick Label contours and set the Label interval, Size and Decimals.
  5. Apply, then OK to keep it.

Show which wells have which data (Attribute Map)

Where: Map toolbar ▸ Attribute Map…

  1. Open the Map and press Attribute Map… on the toolbar.
  2. Add attributes (LAS, raster, core, directional survey, production...) with Add to the map; order them with ▲ ▼.
  3. Tick Show the Attribute Map, set the Ring size and Legend, then Apply.

Raster logs and the digitizer

Digitize a curve from a raster log

Where: Raster tab ▸ Digitize… (on a registered raster)

  1. Select a registered raster and press Digitize….
  2. New curve…: mnemonic, type, units, the values at the track's edges, wrapping and sampling.
  3. Left edge / Right edge: click each edge of the curve's track.
  4. Point clicks along the curve; Manual Trace draws it; Auto Trace follows it from one click.
  5. Edit: drag nodes, click the line to add one, select and Delete. Save curve to well writes a LAS curve into the well.

Import a raster log (image or PDF)

Where: Geo Workbench ▸ Well Manager ▸ Raster tab ▸ Add raster image… / Import PDF log… / Import Petra rasters (.lic)…

  1. Select the well and open the Raster tab.
  2. Add raster image… (TIFF, PNG or JPEG), Import PDF log… (pages joined into one image) or Import Petra rasters (.lic)….
  3. Then register it to depth with Calibrate….

Register a raster log to depth (depth ties, edges)

Where: Raster tab ▸ Calibrate… (the registration window)

  1. Select the raster and press Calibrate… (or double-click it).
  2. Click a depth line you can read, type its depth, Enter; do the same for a second one: depth lines appear every interval.
  3. Where the scan has stretched, click the log's line and accept or type the depth: each is a red hard line (drag to move, Delete to remove).
  4. The edges mode sets the left and right limits of the useful width. Auto register can propose ties for review.

Repair a bad trace segment

Where: Digitizer: Edit mode and a node's right-click menu

  1. In Edit mode drag a box (or Shift-click) over the bad nodes and press Delete.
  2. Trace that stretch again with Point, Manual Trace or Auto Trace; near the end of a segment it carries on.
  3. Right-click a node for: Break the curve after this node, Join this segment to the next, Wrap to the next / previous scale, Smooth selected segment, Delete this whole segment.
  4. Ctrl+Z undoes, Ctrl+Y redoes.

Petro Workbench

Add more wells to a Petro project

Where: Petro Workbench: File ▸ Add new well from LAS… / Add multiple wells from LAS…

  1. Choose File ▸ Add new well from LAS… for one well, or File ▸ Add multiple wells from LAS… for several.
  2. Pick the LAS files; each becomes a well in the project tree (Activate Well switches between them).

Calculate shale volume (Vsh)

Where: Petro Workbench toolbar ▸ Equations

  1. Press Equations on the toolbar.
  2. Choose a built-in: Linear GR shale volume, Larionov Vsh — Tertiary rocks / Older rocks, Clavier Vsh or Stieber Vsh; edit GR_CLEAN and GR_SHALE (and curve names) in the text.
  3. Pick the Calculation interval, Run Preview, check the curve on the logs, then Accept… to keep it (Discard drops it).

Calculate water saturation (Archie, Simandoux, Dual Water, Waxman-Smits)

Where: Petro Workbench toolbar ▸ Equations

  1. Press Equations on the toolbar.
  2. Choose Archie water saturation, Indonesian water saturation, Simandoux water saturation, Dual Water saturation (N=2) or Waxman-Smits saturation (N=2).
  3. Edit the constants (A, M, N, RW, RSH, RWB, SWB, B, QV) and curve names in the text; porosity and Vsh are used as stored (write PHIE / 100 for a curve in percent).
  4. Run Preview, check, then Accept….

Constraints

  • Every input curve must be on one sample grid (see the common-depth requirement).

Change the curve display (Track Manager)

Where: Petro Workbench toolbar ▸ Track Manager

  1. Press Track Manager on the toolbar.
  2. Choose a track, select curves under Available curves and Add →.
  3. Select an assigned curve to set Min / Max, Reverse, Color, Thickness and scale grid, then Save curve display and scale grid. Tick the box beside a curve to hide or show it.

Define pay flags (cut-offs) and their PhiH

Where: Petro Workbench toolbar ▸ Interpretation ▸ Pay Flags tab

  1. Define a zone first: Interpretation ▸ Zones tab (Add zone).
  2. On the Pay Flags tab give a name, choose the Zone and the output curve, and type the cut-offs (one per line, for example PHIE >= 0.08).
  3. Add & Generate makes the 0/1 flag curve and shows gross, net, N:G, average porosity and Sw, and phi-h.
  4. In a project well the summary is saved to Geo as zone values ("<pay name> phi-h" ...) for maps and bubbles.

Edit curves (Curve Editor)

Where: Petro Workbench toolbar ▸ Curve Editor

  1. Press Curve Editor on the toolbar.
  2. Choose the source curve and the operation (resample, shift, smooth...), set its parameters and Preview Edit.
  3. Accept Edit keeps it; Discard drops it. Duplicate, Rename and Delete manage curves.

Load LAS logs into Petro

Where: Petro Workbench: File ▸ Start new project from LAS… / Add LAS run to active well…; project wells: Geo ▸ Project ▸ Open Petro Workbench

  1. Project wells: in Geo choose Project ▸ Open Petro Workbench; Petro opens the project's wells and their LAS.
  2. Standalone: File ▸ Start new project from LAS… and pick the files.
  3. To add another logging run to the active well: File ▸ Add LAS run to active well….

Make crossplots and histograms

Where: Petro Workbench toolbar ▸ Interpretation ▸ Crossplots / Histograms…

  1. Press Interpretation on the toolbar, then Crossplots / Histograms….
  2. Choose the curves, Plot mode, bins, axis ranges and colours; the Pickett Plot box draws Sw lines.

Notes

  • Statistics on the toolbar gives curve and core statistics over an interval.

Overlay core data on the logs

Where: Petro Workbench toolbar ▸ Core / Perf ▸ Core Dataset Manager… / Import Core Dataset CSV…

  1. Press Core / Perf on the toolbar.
  2. Import Core Dataset CSV… brings measurements in; Core Dataset Manager… sets each dataset's track, scale, marker and colour.
  3. Perforations and core intervals are posted as bands from the same window.

Why a curve cannot be calculated (curves on different sample grids)

Where: Petro Workbench: Equations (the check before calculating); fix with Curve Editor ▸ Resample

  1. Petro calculates only when every input curve is on one sample grid (same step and depths).
  2. When they differ it says which curves and offers to resample: the Curve Editor opens on Resample with the target grid filled in.
  3. Accept the resampled curve, then run the equation again.

If it does not work

  • An input curve is missing: map the mnemonic to a loaded curve, or load it.
  • A curve stored in percent used as a fraction: write PHIE / 100.
  • After the license expires new calculations are refused (saving still works).

Seismic Workbench

Analyze and correct misties

Where: Seismic Workbench: right-click a tie ▸ Analyze Mistie…; Interpretation ▸ Mistie corrections…

  1. At a tie, right-click and choose Analyze Mistie…: choose what to compare; nothing changes.
  2. Store a correction from the analysis, then apply it in Interpretation ▸ Mistie corrections….

Compute seismic attributes

Where: Seismic Workbench: Interpretation ▸ Seismic Attributes… (Window ▸ New Seismic Attributes window)

  1. Choose Interpretation ▸ Seismic Attributes….
  2. Pick the attribute and its settings and view it in its window.

Convert time to depth

Where: Seismic Workbench: Interpretation ▸ Time-Depth Models… / Convert Time to Depth…

  1. Interpretation ▸ Time-Depth Models… sets up the models (wells' time-depth data come from Geo's Time–Depth tab).
  2. Interpretation ▸ Convert Time to Depth… converts horizons with a chosen model.

Export or import horizon and fault picks

Where: Seismic Workbench: right-click a horizon or fault ▸ Export … Picks…; File ▸ Import Seismic Interpretation…

  1. Export: right-click the horizon or fault in the interpretation list and choose Export Horizon Picks… / Export Fault Picks… (Export Horizon Surface… for the gridded surface).
  2. Import: File ▸ Import Seismic Interpretation… (columns mapped in a preview), or File ▸ Import Kingdom Horizon… / Import Kingdom Fault….

Load a 2-D SEG-Y line and its navigation

Where: Seismic Workbench: File ▸ Load 2-D SEG-Y line… / File ▸ Import SEG-P1 / SP1 Navigation…

  1. Choose File ▸ Load 2-D SEG-Y line… and pick the file.
  2. Choose File ▸ Import SEG-P1 / SP1 Navigation… to position it: read, preview and import; the line's map shows supplied and interpolated positions.

Load a 3-D SEG-Y survey

Where: Seismic Workbench: File ▸ Load SEG-Y survey…

  1. Open the project (Geo: Project ▸ Open Seismic Workbench, or File ▸ Open project…).
  2. Choose File ▸ Load SEG-Y survey… and pick the file; check the geometry Workbench reads.
  3. Survey ▸ Survey properties… and Display settings… adjust it later.

Make a grid from a horizon

Where: Seismic Workbench: right-click the horizon in the interpretation list ▸ Save / Update Horizon Grid…

  1. Right-click the horizon in the interpretation list and choose Save / Update Horizon Grid….
  2. The picks are gridded into the horizon's project grid (made or updated); the picks are not changed.
  3. The grid is listed on Geo's Map Grids tab: Map ▸ Grid Display… sets its colours and contours.

Pick a horizon

Where: Seismic Workbench: Interpretation ▸ New horizon…, then the toolbar's Horizon / Add

  1. Open a section: Window ▸ New inline (or the Inline / Crossline buttons).
  2. Interpretation ▸ New horizon… (or New… on the toolbar), and make it the active horizon in the box beside Horizon / Fault.
  3. Choose Horizon and Add on the toolbar, set Snap, then click along the event on the section. Edit and Delete change picks.
  4. Auto Pick… extends picks; Interpretation ▸ Undo steps back. Picks are saved automatically.

Pick faults

Where: Seismic Workbench: Interpretation ▸ New fault…, then the toolbar's Fault / Add

  1. Interpretation ▸ New fault… (or New unassigned fault) and make it active.
  2. Choose Fault and Add on the toolbar and click along the fault on a section: each section's clicks make a stick.
  3. Right-click a stick to delete it or assign it to another fault.

Tie a 2-D line to a 3-D survey (and other lines)

Where: Seismic Workbench: right-click a 2-D line's section ▸ Ties on this line / Open 3D tie section… / Tie to 3D here

  1. Load the 2-D line with its navigation and the 3-D survey in a common coordinate system.
  2. Open the line's section, right-click it: Ties on this line lists where it crosses other lines and enters or leaves the survey.
  3. Open 3D tie section… (or Tie to 3D here) shows the 3-D along or across the line; Open Tie View shows both side by side.
  4. Picks are shown as they are: nothing is shifted unless you run Analyze Mistie… and apply a correction.

Correlation Workbench

Save and reopen a correlation layout

Cross Section

Geosteering Workbench

Create or open a geosteering job

Where: Geosteering Workbench: File ▸ New job / Open job… / Open a lateral from the project…

  1. File ▸ New job starts one; File ▸ Open job… opens a saved .ogsteer file.
  2. In a project: File ▸ Open a lateral from the project… (the job is kept in the project).
  3. Job ▸ Properties… sets the target, curves and plan.

Interpret horizons along the lateral

Where: Geosteering Workbench: Interpretation ▸ Start interpretation

  1. Interpretation ▸ Start interpretation (or right-click ▸ Start interpretation here).
  2. Drag segment handles on the section, or segments in the correlation window, to match the lateral's log to the type log; double-click splits a segment.
  3. Insert fault… places a fault (type its throw); Undo / Redo step back and forward.

Load the type well and the lateral's survey

Where: Geosteering Workbench: Wells ▸ Type well… / Lateral well… (or … from the project)

  1. Wells ▸ Type well… (or Type well from the project…) loads the offset well with its log and tops.
  2. Wells ▸ Lateral well… (or Lateral from the project…) loads the lateral's survey and LAS.

Reload changed source files (watch files)

Where: Geosteering Workbench: Wells ▸ Read files again (F5) / Watch files for updates (real time)

  1. Wells ▸ Read files again (F5) rereads the lateral's survey and LAS files that changed.
  2. Wells ▸ Watch files for updates (real time) checks them every 15 seconds.

If it does not work

  • After the license expires changed files are noticed but not read (the status line says so); a valid new license reads them.

Set a predrill prognosis

Where: Geosteering Workbench: Job ▸ Predrill prognosis… / Job ▸ Prognosis from a map grid…

  1. Job ▸ Predrill prognosis… enters the structural tops along the lateral before it is drilled.
  2. Job ▸ Prognosis from a map grid… takes the planned tops from a project grid.
