## 5. Targeted v0.9.72 Verification

Perform additional investigation of the latest changes.

### Petra LIC Import

Verify:

- Import dialog opens before LIC parsing.
- User-selected raster folder overrides embedded LIC paths.
- Recursive image lookup works reliably.
- Ambiguous images aren't selected silently.
- Add New, Update Existing, and Add/Update behave correctly.
- Existing raster identity matching is reliable.
- Original LIC overwrite requires permission.
- Backup and atomic replacement work.
- Existing registrations and digitized curves are protected.
- Batch failures are isolated.
- Import results persist after closing and reopening.

Test using realistic LIC variations as well as synthetic files.

### TVD Pay Convention

Verify:

- Conventional wells retain correct TVD pay.
- Non-monotonic intervals return N/A for TVD pay and N:G.
- No automatic MD substitution occurs.
- MD interval length remains separately identified.
- Petro, Batch Zones, exports, and maps handle N/A consistently.
- Protected Cython modules match their source implementations.

## 10. Finding Classification

Classify every finding:

- **Critical:** Data loss, corruption, native crash, serious security failure.
- **High:** Major correctness, persistence, or operational defect.
- **Medium:** Functional defect, inconsistent behavior, or important reliability issue.
- **Low:** Minor functional or usability defect.
- **Cleanup:** Redundant, obsolete, or inconsistent code requiring correction.

Every finding must include:

1. Unique ID.
2. Severity.
3. Exact file and function.
4. Line references.
5. Root cause or supported hypothesis.
6. Reproduction steps.
7. Expected and observed behavior.
8. Test evidence.
9. Recommended correction.
10. Potential regression risks.

Use the prefix `FA72-` for new findings.

Preserve earlier IDs for previously reported issues.

Do not omit findings solely because they are cosmetic or low priority.
